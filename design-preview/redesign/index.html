更新至 12 集 · 还剩 26 分钟
正文字 — PingFang SC / HarmonyOS Sans 系统栈。承担一切元数据与操作文案，保持克制，让宋体只在该发光的地方发光。

设计要点

  • 琥珀 = 可交互。整套界面只有一个亮色：播放按钮、当前集、焦点框、进度条。视线扫过页面时，亮的地方就是能按的地方。
  • 电视端焦点即放映灯。焦点卡片放大 9%、琥珀描边、底部向下投一片暖光——像放映机照亮了这张海报。遥控器上下左右，光走到哪里，哪里就是舞台。
  • 印章只做三件事。Logo「映」、榜首「热」、新集「新」。朱红面积被刻意压到最小，多一处都会俗。
  • 底栏只做三件事。首页 / 直播 / 设置。收藏与历史不占底栏——它们是"回访"动作，收进设置页顶部两张大卡，带海报缩影与更新角标，一眼能看到有没有新集。
  • 真实词汇。线路 / 换源 / 测速 / 选集 / 弹幕 / 按键提示，全部来自 TVBox 的真实概念，落地时文案可直接复用。
  • 无障碍底线。暖白 #F3EEE3 对影厅黑对比度约 15:1；已看集数只降亮度不缩字号；prefers-reduced-motion 下关闭全部动效。
预览方式：直接双击打开任意 HTML，或在 design-preview/redesign 目录起本地服务。字体走 Google Fonts， 离线时自动回退系统宋体（macOS: Songti SC / Windows: SimSun），版式不受影响。
落地对应：手机端 → mobile flavor（VodFragment 首页 / VideoActivity 详情）；电视端 → leanback flavor（HomeActivity / VideoActivity）， 焦点样式对应 leanback 的 FocusHighlight 与自定义 selector。
